Recommended workflow

Turn each exercise into a complete study cycle

  1. Contract: state shapes, units, frames, boundary behavior, invalid-input policy, and complexity.
  2. Oracle: work a tiny example by hand and encode it as a test before implementation.
  3. Implementation: write the smallest correct baseline, then compare with a trusted library.
  4. Failure: construct a degenerate, noisy, empty, large, or asynchronous case that breaks a naive version.
  5. Measure: profile representative workloads and protect numerical/task quality.
  6. Explain: defend assumptions, rejected alternatives, production changes, and the current bottleneck.
