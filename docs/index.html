The development of vision theory

One evolving answer to: what is in the scene?

Study each era as a change in assumptions—not a list of model names. Modern systems combine ideas from every stage.

Follow the full theory path
  1. 1960s–1980s

    Geometry & image formation

    Projective cameras, edges, shape, stereo, and the physical constraints that make pixels measurable.

  2. 1980s–2000s

    Handcrafted representation

    Scale space, corners, SIFT/HOG, optical flow, and robust estimation turn structure into algorithms.

  3. 1995–2012

    Statistical learning

    Probabilistic models, graphical models, boosting, SVMs, and engineered features learn decisions from data.

  4. 2012–2017

    Deep convolution

    Representation learning scales detection, segmentation, pose, and dense prediction end to end.

  5. 2017–2021

    Attention & 3D context

    Transformers, multi-view geometry, depth, tracking, and BEV fuse spatial and temporal evidence.

  6. 2021–present

    Foundation & world models

    Self-supervision, vision-language models, open vocabulary, occupancy, and generative scene prediction.

The senior learning loop

Do not stop at familiarity

A topic becomes interview- and production-ready only after it survives implementation, measurement, and critique.

01

Predict

State the expected behavior before touching the experiment.

02

Derive

Recover the equation, assumptions, observability, and limits.

03

Implement

Build the smallest correct version with explicit tests.

04

Measure

Choose metrics and slices before comparing solutions.

05

Break

Create edge cases and name the real failure mechanism.

06

Ship

Profile, document, teach, and package reproducible evidence.
