The development of vision theory

One evolving answer to: what is in the scene?

Study each era as a change in assumptions—not a list of model names. Modern systems combine ideas from every stage.

Follow the full theory path
  1. 1960s–1980s

    Geometry & image formation

    Projective cameras, edges, shape, stereo, and the physical constraints that make pixels measurable.

  2. 1980s–2000s

    Handcrafted representation

    Scale space, corners, SIFT/HOG, optical flow, and robust estimation turn structure into algorithms.

  3. 1995–2012

    Statistical learning

    Probabilistic models, graphical models, boosting, SVMs, and engineered features learn decisions from data.

  4. 2012–2017

    Deep convolution

    Representation learning scales detection, segmentation, pose, and dense prediction end to end.

  5. 2017–2021

    Attention & 3D context

    Transformers, multi-view geometry, depth, tracking, and BEV fuse spatial and temporal evidence.

  6. 2021–present

    Foundation & world models

    Self-supervision, vision-language models, open vocabulary, occupancy, and generative scene prediction.

The study loop

Do not stop at familiarity

A topic becomes usable knowledge only after it survives derivation, comparison, implementation, measurement, and critique.

01

Predict

State the expected behavior before touching the experiment.

02

Derive

Recover the equation, assumptions, observability, and limits.

03

Implement

Build the smallest correct version with explicit tests.

04

Measure

Choose metrics and slices before comparing solutions.

05

Break

Create edge cases and name the real failure mechanism.

06

Explain

Document the choice, rejected alternatives, results, and remaining uncertainty.

Choose by problem constraints

There is no universally best vision method

Start with the output you need, then narrow the choices using geometry, sensors, latency, supervision, and failure cost.

2D image output

Detection or segmentation?

Choose detection for object identity and extent; segmentation when boundary or occupied pixels change the decision.

  • YOLO: strong real-time baseline
  • DETR family: set prediction and global matching
  • Mask models: contours, parts, and free space
Metric 3D output

Which source of depth?

Use monocular depth for low sensor cost, multi-view geometry for measured parallax, or LiDAR fusion when reliable range is worth the hardware.

  • Single camera: ambiguous scale and occlusion
  • Multi-camera/temporal: more geometry, more calibration
  • LiDAR: direct range, sparse samples and added cost
Novel-view output

Geometry or appearance?

Use meshes when editable surfaces matter, NeRF for continuous radiance fields, and Gaussian methods for fast high-quality view synthesis.

  • Mesh: explicit and editable, harder reconstruction
  • NeRF: compact continuity, slower rendering/training
  • 3DGS/3DGRUT: fast rendering or flexible ray effects

Decision flow

Output → constraints → candidates → falsifying test

Define the coordinate frame and required uncertainty first. Remove methods that cannot meet sensor, latency, memory, or supervision constraints. Compare the survivors at one operating point, then choose the simplest method that passes the failure slices that matter.
