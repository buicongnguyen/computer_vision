Module 05 · Modern CV

From engineered features to visual foundation systems

Understand why each major architecture appeared, what mechanism it introduced, which old assumptions it retained, and where it fails when placed inside a real perception product.

Study contract

Reason from mechanism, not model names

Study each architecture as a bundle of assumptions and tradeoffs rather than a leaderboard entry. Derive tensor shapes, state the training signal, identify hidden data assumptions, choose an evaluation protocol, and explain the latency and memory consequences.

Theory evolution

Every gain moves the bottleneck

Major transitions in modern computer vision and the engineering debt each transition introduced.
Stage Main mechanism What improved New cost or weakness Still the right choice when…
Classical pipeline Designed filters, invariant descriptors, geometric verification, shallow classifiers Interpretability, low data demand, explicit geometry Brittle features and task-specific engineering Data or compute is scarce, geometry dominates, or auditability matters
CNN recognition Learned local kernels, weight sharing, hierarchical receptive fields End-to-end feature learning and strong visual priors Large labeled datasets, texture shortcuts, limited global context Latency, mature accelerators, dense prediction, and stable deployment dominate
Residual and feature-pyramid CNNs Skip connections and multi-scale feature hierarchies Deeper optimization and better small-object coverage Complex necks, hand-designed scale routing, memory traffic Multi-scale detection needs predictable speed and proven kernels
Vision transformers Patch tokens, global content-dependent attention, large-scale pretraining Long-range interactions and scalable representations Quadratic token interaction, weak built-in locality, data hunger Pretraining is available and global or multimodal context is valuable

Generative, neural 3D, and world models Learned distributions over pixels, scenes, or future latent states Synthesis, reconstruction, simulation, and predictive state Expensive inference, geometric inconsistency, causal ambiguity, weak guarantees The product benefits from simulation, editing, view synthesis, or planning

Mechanism 01

From local convolution to token interaction

Classical descriptors: invariance by design

Classical systems separate the problem into detection, description, matching, geometric verification, and a task head. A descriptor is engineered to suppress nuisance variation while preserving identity. That separation remains valuable for debugging and for geometry-heavy tasks, but the chosen invariance can discard information the downstream task needs.

Decision question: should illumination change be removed, modeled, or used as a cue? The answer differs for place recognition, photometric stereo, and defect inspection.

CNNs: invariance learned under a locality prior

For output channel cₒ at pixel p, a convolution applies the same local weights everywhere:

y[cₒ, p] = σ( Σ[cᵢ, Δ] W[cₒ, cᵢ, Δ] · x[cᵢ, p + Δ] + b[cₒ] )

Weight sharing gives translation equivariance before striding and boundary effects. Depth expands the effective receptive field; pooling or striding trades spatial precision for robustness and compute. Residual connections make the learned mapping y = x + F(x), improving gradient flow and allowing deep models to preserve useful identity features.

ViTs: interaction is selected by content

An image is split into patches, projected to tokens, augmented with position information, and processed using self-attention:

Q = XWq,  K = XWk,  V = XWv
Attention(X) = softmax(QKᵀ / √d) V

Unlike a fixed convolutional stencil, each token can mix information from any other token. This gains global context but makes full attention cost roughly O(N²d) in compute and O(N²) in attention memory for N tokens. Smaller patches improve detail while rapidly increasing cost.

Design rule

Inductive bias is prepaid data efficiency

CNN locality and weight sharing constrain the hypothesis space, so less data may be needed. A transformer relaxes those assumptions and can learn broader interactions, but the missing prior must be supplied by data, objective design, architecture, or hybrid local attention. Choose the bias that matches the operating regime.

Mechanism 02

DETR reframes detection as set prediction

Traditional detectors predict many overlapping candidates and then use heuristics such as anchors, IoU thresholds, and non-maximum suppression. DETR introduces a fixed set of learned object queries. Each query attends to image features and emits either one object or “no object.” Because ground-truth objects have no order, training first finds a one-to-one assignment.

σ̂ = arg min over permutations σ  Σᵢ Cmatch(yᵢ, ŷσ(i))

Lset = Σᵢ [ Lclass(cᵢ, ĉσ̂(i))
           + λ1 · ||bᵢ - b̂σ̂(i)||₁
           + λIoU · LIoU(bᵢ, b̂σ̂(i)) ]

The Hungarian assignment makes duplicates expensive: only one query can own a target. The decoder therefore learns both what an object is and which query should claim it.

Mechanism trace

Where the clean abstraction becomes engineering work

Vanilla global attention can be expensive at high resolution, sparse small objects may receive weak gradients, and early matching can be unstable. Multi-scale features, deformable sampling, denoising queries, stronger initialization, and iterative box refinement address parts of the problem, but each reintroduces design choices. “End to end” does not mean “free of heuristics”; it means the interfaces and losses have moved.

Mechanism 03

Self-supervision defines what should stay the same

Contrastive learning

Two augmented views of one sample are a positive pair; other samples form negatives. A common per-example objective is:

Li = -log [ exp(sim(zᵢ, zᵢ⁺) / τ)
            / Σⱼ exp(sim(zᵢ, zⱼ) / τ) ]

The temperature τ controls how sharply hard negatives dominate. Augmentations encode the invariances: aggressive cropping may help classification yet harm counting or geometry.

Masked modeling

A large fraction of image tokens is hidden and the model reconstructs pixels, features, or discrete targets:

Lmask = (1 / |M|) Σ[i ∈ M] || targetᵢ - decoder(encoder(xvisible))ᵢ ||²

Masking forces contextual prediction and avoids explicit negatives. The target choice determines whether the representation emphasizes texture, semantics, or geometry.

Teacher-student learning

A slowly updated teacher supplies targets to a student under different views. Centering, sharpening, stop-gradient paths, or variance constraints prevent constant representations. Collapse prevention is a mechanism, not a minor training trick.

θteacher ← m · θteacher + (1 - m) · θstudent

Foundation representation is an evaluation claim

A large encoder becomes “foundational” only if its features transfer across meaningful shifts in tasks, labels, domains, viewpoints, and data scale. Linear probing measures accessibility under a frozen representation; fine-tuning measures adaptability; retrieval tests metric structure; dense tasks expose whether spatial detail survived. A single benchmark cannot establish generality.

Mechanism 04

Open-vocabulary perception aligns pixels with language

A dual-encoder vision-language model maps an image and text descriptions into a shared normalized space. For image embedding v, text embedding tₖ, and learned scale s:

logit(image, class k) = s · cosine(v, tₖ)
p(k | image) = softmax over k [ logit(image, class k) ]

Replacing a fixed classifier matrix with text embeddings makes the vocabulary editable at inference time. Detection and segmentation systems extend the idea by aligning regions, pixels, or object queries with language. A generative VLM instead conditions a language decoder on visual tokens and can answer, describe, or reason through text.

What “open vocabulary” does not guarantee

  • Open world: scoring arbitrary labels does not guarantee reliable unknown rejection.
  • Grounding: image-level alignment can recognize a concept without localizing it.
  • Compositionality: object and attribute familiarity does not ensure correct relations or counting.
  • Calibration: prompt wording and class-list composition can change confidence.
  • Fresh knowledge: language coverage is bounded by training data and the visual evidence actually present.

Production pattern: use prompt ensembles and curated taxonomies offline, cache text embeddings, calibrate on the target domain, maintain an explicit unknown path, and route low-confidence cases to a specialist model or human workflow.

Mechanism 05

Diffusion learns to reverse controlled corruption

Forward and reverse processes

The forward process adds Gaussian noise according to a known schedule. A noisy sample can be produced directly:

xt = √ᾱt · x0 + √(1 - ᾱt) · ε,    ε ~ N(0, I)

A network predicts the injected noise, velocity, clean sample, or score. In the noise-prediction form:

Lsimple = E[x0, ε, t] || ε - εθ(xt, t, condition) ||²

Conditioning and guidance

Text, masks, depth, pose, edges, or reference images condition denoising. Classifier-free guidance combines conditional and unconditional predictions:

εguided = εuncond + w · (εcond - εuncond)

Larger w often increases condition adherence while reducing diversity or creating artifacts. Guidance is a controllability tradeoff, not a free quality knob.

Generative vision beyond image synthesis

Denoising objectives support editing, restoration, super-resolution, data generation, probabilistic depth, future prediction, 3D priors, and planning proposals. Their value comes from modeling a distribution rather than only a point estimate. Their cost is iterative inference and difficult verification: a perceptually plausible sample can still violate identity, geometry, physics, labels, or safety constraints.

Evaluate conditional fidelity, diversity, geometry, temporal consistency, memorization risk, and downstream utility separately. One scalar perceptual score is insufficient.

Mechanism 06

NeRF and Gaussian splatting trade rendering structure

NeRF: continuous field + volume rendering

A neural field maps a 3D point and view direction to density σ and color c. Samples along a camera ray are composited front to back:

αi = 1 - exp(-σi · δi)
Ti = exp(-Σ[j<i] σj · δj)
C(ray) = Σi Ti · αi · ci

Camera poses tie 2D observations into a shared 3D field. Differentiable rendering lets image error supervise geometry and appearance indirectly. Rendering can be expensive because many field evaluations are required per ray.

Gaussian splatting: explicit primitives + rasterization

A scene is represented by anisotropic 3D Gaussians with position, covariance, opacity, and appearance. Projection yields a 2D elliptical footprint:

αi(u) = oi · exp[-½ (u - μi)ᵀ Σi⁻¹ (u - μi)]
C(u) = Σi ci · αi(u) · Π[j<i](1 - αj(u))

Fast tile-based rasterization gives high interactive rendering speed, but the explicit primitive set can consume substantial memory and requires densification, pruning, sorting, and careful handling of visibility.

Decision factors for neural radiance fields and Gaussian splats.
Question Neural field tendency Gaussian tendency
Representation Implicit continuous function Explicit adaptive primitives
Rendering Ray sampling and integration Projection, sorting, and alpha compositing
Typical strength Compact continuous modeling and flexible field queries Fast high-quality novel-view rendering
Typical risk Slow training/rendering and floaters under weak coverage Memory growth, primitive management, and geometry ambiguity
Shared dependency Accurate calibration, adequate view coverage, a suitable scene model, and validation beyond photometric quality

Mechanism 07

World models make perception action-conditional

A recognition model estimates what is visible now. An embodied system needs state relevant to future decisions: geometry, motion, uncertainty, affordances, and the consequences of action. A compact latent dynamics model can be written as:

zt = encoder(observationt)
ẑt+1 ~ pθ(zt+1 | zt, at)
ô t+1 = decoder(ẑt+1)

Training may combine representation, prediction, reconstruction, reward, value, or action losses:

L = λrep Lrepresentation + λdyn Lprediction
  + λtask Ltask + λunc Luncertainty

The central design choice: what must the latent preserve?

Pixel prediction rewards appearance detail; feature prediction can emphasize semantics; occupancy or flow rewards geometric dynamics; reward/value prediction keeps decision-relevant information. No single target is universally sufficient. A latent that renders attractive video may ignore a small obstacle; a state optimized only for reward may be hard to audit.

Open-loop versus closed-loop evidence

Future-frame quality, trajectory error, or latent loss is open-loop evidence. An embodied system must also be tested closed loop with interventions, recovery from error, counterfactual actions, long-tail scenarios, and uncertainty-aware fallback. Small prediction bias compounds when the model's own outputs change the next observation distribution.

Failure analysis

Current limitations to design around

Distribution

Shortcut learning and shift

Models exploit background, capture pipeline, text, or dataset artifacts. Random train/test splits can hide correlated leakage. Validate across time, geography, device, weather, and collection policy.

Confidence

Open-set calibration

Softmax or similarity scores need not reflect correctness under novelty. Separate ranking quality, probabilistic calibration, unknown detection, and selective-risk behavior.

Structure

Geometry and temporal consistency

Strong semantic models can violate epipolar geometry, object permanence, scale, or motion. Add explicit geometric tests and sequence-level metrics instead of trusting frame-wise accuracy.

Language

Hallucination and grounding gaps

VLM output may follow language priors when evidence is absent. Require evidence localization, abstention, constrained vocabularies, retrieval, or tool verification for high-impact decisions.

Generation

Plausibility is not truth

Diffusion and world models can produce convincing but physically or semantically wrong samples. Generated data needs provenance, coverage analysis, and downstream validation against real data.

Systems

Average speed hides tail failures

Dynamic shapes, preprocessing, memory allocation, data transfer, throttling, and batching change latency. Measure end-to-end percentiles on the target hardware and workload.

Evidence before adoption

Evaluation must cover task, uncertainty, and system

A minimum evidence matrix for modern vision systems.

Classification Accuracy, macro F1, per-class recall Tail classes, domain, corruption, time ECE or reliability curves, selective risk, latency
Detection / segmentation AP by IoU and size; mIoU, Dice, PQ, boundary quality Range, scale, occlusion, density, weather False negatives by hazard, temporal stability, peak memory
Open-vocabulary / VLM Open-vocabulary AP, retrieval recall, grounded QA Prompt templates, synonyms, unseen compositions, unknowns Abstention, evidence grounding, hallucination rate, cache cost
Generative vision Distributional, perceptual, condition-fidelity, and human measures Identity, text, geometry, temporal length, rare conditions Memorization, safety filters, sampling steps, energy and throughput

Calibration is decision-specific

Expected calibration error bins confidence and compares mean confidence with empirical accuracy:

ECE = Σb (|Bb| / n) · | accuracy(Bb) - confidence(Bb) |

ECE can hide local failures. Also inspect class-conditional reliability, risk-coverage curves, threshold stability, and calibration after deployment transformations such as quantization.

Production budget is a vector

Track end-to-end p50/p95/p99 latency, throughput at the intended batch size, peak and steady memory, startup time, power, model size, data-transfer cost, and recovery behavior. FLOPs alone miss memory bandwidth, kernel launch overhead, operator support, and host-device synchronization.

Deployment gate

Compare complete systems under one operating point

Fix input policy, precision, hardware, batch size, warm-up, confidence threshold, post-processing, and data slices before comparing models. Report Pareto frontiers rather than naming a single winner. Re-run quality tests on the exported engine; graph rewrites and reduced precision can change predictions.

Learning branches

Choose the next topic by the unresolved question

Three useful directions

Branch A · representation

How does supervision shape a reusable visual feature?

  • Design leakage-resistant data splits and long-tail slices.
  • Compare frozen, adapted, and task-specific representations.
  • Build reproducible distributed experiments and ablations.
  • Explain calibration, privacy, fairness, and monitoring choices.

Compare: supervised pretraining, contrastive learning, masked image modeling, and vision-language alignment under the same transfer protocol.

Branch B · computation

Which architectural cost controls deployment?

  • Profile kernels, memory traffic, layout changes, and transfers.
  • Use mixed precision, quantization, fusion, and shape constraints deliberately.
  • Distinguish throughput optimization from real-time tail latency.
  • Validate exported engines numerically and task-wise.

Compare: convolution, global or windowed attention, precision, compilation, batching, and memory movement on one target runtime.

Branch C · 3D and time

Which representation supports spatial reasoning?

  • Connect calibration and coordinate frames to 3D or BEV outputs.
  • Handle multi-camera timing, occlusion, motion, and uncertainty.
  • Evaluate by range, weather, agent type, map context, and hazard.
  • Define closed-loop fallbacks and monitor calibration drift.

Compare: depth maps, point clouds, object tracks, BEV features, occupancy, meshes, radiance fields, and Gaussian primitives.

Original practice

Turn mechanisms into testable judgment

Theory prompts

Derive and explain

  1. Prove convolution is translation equivariant when boundary and stride effects are ignored. Give two ways a production CNN breaks exact equivariance.
  2. For a 224×224 image, compare token count and attention-matrix size for patch sizes 16 and 8. Explain the effect on small objects.
  3. Construct a three-prediction, two-target matching-cost matrix and solve the optimal DETR assignment by hand. Show why greedy matching can fail.
  4. Explain how contrastive temperature changes gradient emphasis. Predict two symptoms when it is much too small.
  5. Derive front-to-back transmittance in volume rendering from independent absorption over ray intervals.

Coding prompts

Implement and test

  1. Implement patchification and unpatchification with shape assertions and a round-trip test. Add non-square images and non-divisible dimensions to the test plan.
  2. Implement scaled dot-product attention without a high-level attention layer. Test mask broadcasting, gradient flow, and numerical stability at large logits.
  3. Implement InfoNCE for a symmetric image/text batch. Verify that aligned embeddings lower loss and report retrieval recall.
  4. Implement discrete NeRF compositing for one ray. Numerically test empty space, an opaque surface, and sample-order errors.
  5. Export one detector at two precisions and compare task metrics, output drift, p50/p99 latency, memory, and warm-up behavior.

System-design prompts

Defend a decision

  1. Design an open-vocabulary detector for a changing retail catalog. Specify prompt policy, unknown handling, annotation loop, calibration, and rollback.
  2. Choose between a CNN, ViT, and hybrid backbone for a 30 FPS edge device. Ask for missing constraints before proposing an answer.
  3. Design evaluation for synthetic weather data used to train an autonomous perception model. Separate realism, coverage, leakage, and downstream utility.
  4. Review a world model whose open-loop video quality improved while closed-loop driving worsened. Propose hypotheses and discriminating experiments.
  5. Plan migration from a dense anchor detector to a DETR-family model without interrupting service. Include shadow traffic, metric parity, threshold recalibration, and fallback.

Completion rubric

For every answer, expose the reasoning chain

State assumptions, tensor shapes, objective, baseline, metric, data slice, system budget, expected failure, and a falsifying experiment. A plausible architecture diagram without this chain is not a complete technical answer.
